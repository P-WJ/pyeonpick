- **현재 상황**: 비어있는 상태에서 "조건에 맞는 상품이 없습니다"만 표시됩니다.
- **권장 해결**: 검색/필터 결과가 0개일 때 "필터 초기화" CTA 버튼 추가
  ```
  {showEmptyState && (
    <div className="...">
      <p>조건에 맞는 상품이 없습니다.</p>
      <button onClick={resetFilters}>필터 초기화</button>
    </div>
  )}
  ```

### 2. **로그인 없이 게시글 작성 시도 시 피드백 부족** — `board/page.tsx` + `board/[id]/page.tsx`
- **문제**: 비로그인 사용자가 "글쓰기" 버튼을 클릭해도 리다이렉트만 되고, 왜 로그인이 필요한지 안내가 불충분합니다.
- **현재 상황**: `WritePage`에서는 `useSession` 체크 후 자동 리다이렉트되지만, 사용자는 이유를 모릅니다.
- **권장 해결**: 
  - 토스트 메시지: "게시글 작성을 위해 로그인이 필요합니다"
  - 또는 모달로 로그인 유도

### 3. **모바일(375px)에서 필터 버튼 겹침** — `FilterBar.tsx`
- **문제**: 편의점/행사 필터 버튼들이 모바일 화면에서 2-3줄로 나뉘면서 터치 타겟이 44px 미만이 될 수 있습니다.
- **현재 상황**: `flex flex-wrap gap-2`로 자동 줄바꿈하지만, 버튼 높이가 작음 (py-1).
- **권장 해결**: 모바일에서는 수평 스크롤 가능한 그룹으로 변경하거나, 버튼 크기 증가 (py-2)

### 4. **AI 관련 기능이 노출되지만 완성되지 않음** — `AiBanner.tsx`, `AiRecommendModal.tsx`
- **문제**: v1.2 단계 미완성 기능(AI 추천)이 메인 페이지에 노출되어 있습니다.
- **현재 상황**:

  - 클릭하면 모달이 열리고 API 호출 시도 (`/api/ai/recommend`)
  - API가 없으면 에러 표시 (사용자에게 혼란)
- **권장 해결**: 
  - v1.2 완성까지 숨길 방법 필요 (예: 환경변수 플래그)
  - 또는 "곧 출시 예정" 상태로 변경
