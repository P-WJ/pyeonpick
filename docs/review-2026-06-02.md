1. 환경변수명 오류 즉시 수정
2. 상수 통합 및 에러 처리 강화
3. Groq API rate limit 재시도 추가
4. 다중 인스턴스 배포를 고려한 캐시 아키텍처 검토

**단기(완료 전)**: 환경변수 오류 수정 필수
**중기(배포 후)**: 에러 처리/재시도/캐시 아키텍처 개선
**장기(기능 확장시)**: 상수 통합, 캐시 모듈화
