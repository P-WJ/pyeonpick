## 8. frontend/infrastructure/supabase.ts

### 🔴 CRITICAL 보안 이슈 — 필수 수정

**문제**: 줄 5에서 process.env.SUPABASE_SERVICE_KEY를 클라이언트에서 사용

**영향**: 
- 서비스 롤 키(Service Role Key)가 프론트엔드에 노출됨
- 모든 RLS(Row Level Security) 정책이 무력화됨
- 누구나 전체 DB에 접근 가능

**수정 방향**:
1. frontend는 NEXT_PUBLIC_SUPABASE_ANON_KEY 사용 (RLS 정책 적용)
2. 모든 쓰기 작업을 API Route 경유로만 수행
3. 크롤러만 SERVICE_KEY 사용

**현재 (WRONG)**:
```typescript
const key = process.env.SUPABASE_SERVICE_KEY;  // RLS 정책 무력화
```

**수정 후 (CORRECT)**:
```typescript
const key = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY;  // RLS 정책 적용
```

// 개선 예시 (Zod)
import { z } from 'zod';

const ProductSchema = z.object({
  id: z.number(),
  store: z.enum(['CU', 'GS25', '세븐일레븐', '이마트24', '씨스페이스']),
  eventType: z.enum(['1+1', '2+1', '할인']),

});

function mapRowToProduct(row: unknown): Product {

}
