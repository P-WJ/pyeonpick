@agent-ui-designer 에게 UI 개선을 요청해줘.

## 작업 순서

1. `docs/ux-audit-*.md` 파일이 있으면 먼저 읽고 🔴 즉시 수정 항목 파악
2. 없으면 `frontend/app/components/` 직접 읽고 개선점 파악
3. 아래 우선순위 순서로 개선 작업 진행

## 개선 우선순위

### ✅ 이미 완료된 항목 (건드리지 않음)

- 상품 카드 2열 그리드, 행사 뱃지 좌상단, 편의점 뱃지 우상단
- FilterBar 가로 스크롤, 버튼 py-2 터치 타겟
- 장바구니 바텀 바 (담긴 수량 + 절약액)
- 빈 상태 UI (이모지 + CTA + 필터 초기화 버튼)
- 로딩 스켈레톤
- 편의점 브랜드 컬러 (CU 보라, GS25 파랑, 세븐 초록, 이마트24 노랑, 씨스페이스 청록)
- CartDrawer 수량 변경 하이라이트 애니메이션
- ProductCard 혜택 텍스트 ("1개 가격에 2개" 등)
- 비로그인 글쓰기 토스트 안내
- 게시판 댓글 수 시각화

### 1순위 — 고도화 1단계 (미구현)

- [ ] 찜하기: ProductCard에 하트 아이콘 추가, 로컬스토리지(`cvs-wishlist-v1`) 기반
- [ ] 공유 링크 자동 불러오기: URL `?cart=1,2,3` 파싱 → 장바구니 자동 담기
- [ ] UI 폴리싱: 카드 hover 그림자, 버튼 전환 애니메이션 전반 개선

### 2순위 — 고도화 2단계 (미구현)

- [ ] 최근 본 상품: 상세 페이지 접속 시 로컬스토리지 기록, 메인 하단 노출
- [ ] 프로필 페이지 (`/profile`): 찜한 상품, 작성 글 모아보기

## 작업 완료 조건

각 작업 완료 후 `npx tsc --noEmit` 확인.
