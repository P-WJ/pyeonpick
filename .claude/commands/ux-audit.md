@agent-ux-auditor 에게 전체 UX 감사를 요청해줘.

## 감사 범위

`frontend/app/` 의 모든 컴포넌트와 페이지를 읽고 아래 항목을 점검해줘.

### 점검 항목

1. **빈 상태 처리** — 상품 없음, 장바구니 비어있음, 게시글 없음, 댓글 없음, 구독 없음
2. **미완성 기능 노출** — AI 추천 배너/모달이 플래그 없이 노출되는지 (`NEXT_PUBLIC_ENABLE_AI_RECOMMEND`)
3. **모바일 터치 불편** — 터치 타겟 44px 미만, 필터 줄바꿈 등
4. **피드백 누락** — 담기·댓글·구독·로그인 성공/실패 피드백
5. **핵심 기능 작동 여부** — 장바구니·절약액·공유링크·게시판·알림 구독
6. **비로그인 UX** — 글쓰기·댓글 시도 시 안내 있는지
7. **반응형** — 375px 모바일, 768px 태블릿, 1280px 데스크탑

### 미구현 기능 확인 (노출 여부만 체크)

- 공유 링크 자동 불러오기 (URL `?cart=` 파싱)
- 찜하기 기능
- 최근 본 상품
- 프로필 페이지 (`/profile`)
